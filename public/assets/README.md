# Veltacorp — Brand Assets

Drop your real files here, then tell me the filenames (or just use the exact
names below and they'll wire up automatically).

## Required

| File              | What it is                          | Recommended format / size           |
| ----------------- | ----------------------------------- | ----------------------------------- |
| `logo.svg`        | Primary Veltacorp logo (full color) | SVG preferred (or transparent PNG)  |
| `logo-white.svg`  | White/mono logo for dark footer     | SVG or transparent PNG (optional)   |
| `founder.jpg`     | Photo of Abel Joseph                | Portrait, ≥ 800×1000px, well-lit    |
| `hero.jpg`        | Hero background / feature image     | Landscape, ≥ 1920×1080px            |

## Photos (gallery / section imagery)

Name them `photo-1.jpg`, `photo-2.jpg`, … — real photos of sessions, events,
fitness activities or racket sports. Landscape, high resolution.

## Certification / partner badges (optional)

`cert-ace.png`, `cert-firstaid.png`, etc. If not provided, clean icon
placeholders are shown instead.

---

Tip: keep images under ~500KB each where possible (Next.js optimizes them
further). JPG for photos, SVG/PNG for logos and badges.
